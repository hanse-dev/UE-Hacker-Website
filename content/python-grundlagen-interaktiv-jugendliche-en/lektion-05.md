# Conditions with if

`if` runs code only when a condition is true. `elif` checks further conditions, `else` catches everything else.

```python
age = 16
if age >= 18:
    print("Access granted")
elif age >= 16:
    print("Restricted access")
else:
    print("No access")
```

Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
