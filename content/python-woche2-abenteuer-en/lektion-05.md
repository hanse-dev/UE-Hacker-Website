# 💧 Water: Decimal Numbers (`float`)

The Water element is a **decimal number**. Important: Python uses a **point** instead of a comma!

```python
damage = 23.5
percent = 87.25
print(f"Damage: {damage}, hit chance: {percent}%")
print(type(damage))     # <class 'float'>
```

Calculate with a `float`, and the result is a `float` again – even when it comes out even:

```python
print(2.5 * 4)    # 10.0
```
