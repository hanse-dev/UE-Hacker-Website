# Woche 4 – Schleifen (for, while)

## Thema: Code wiederholen

Lerne, wie du Code automatisch wiederholen kannst. Statt denselben Code tausendmal zu schreiben, sag Python: "Mach das automatisch für mich!"

## Die drei Welten

### 🗡️ Abenteuer-Welt
Im magischen Turm entdeckst du, wie sich Muster wiederholen und Zyklen die Realität formen.

### 🐴 Pferde-Welt
Auf dem Trainingsplatz lernst du den Rhythmus des Reitens - Wiederholung führt zur Perfektion.

### 🚀 Sci-Fi-Welt
Im Chronos-Turm manipulierst du die Zeit selbst mit Zeit-Loops und Zyklen.

## Lernziele

- **for-Schleifen** mit `range()` für kontrollierte Wiederholungen
- **while-Schleifen** für flexible Bedingungen
- **Schleifen über Strings**
- **Verschachtelte Schleifen** für komplexe Muster
- **Endlosschleifen** erkennen und vermeiden
