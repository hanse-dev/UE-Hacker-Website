# 🎯 The challenge: Saving data forever!

You want to keep your data not just in memory, but save it permanently and load it again later. Instead of losing data, you can store it in files and exchange it in different formats.

With file I/O, JSON and CSV, your data becomes permanent and available everywhere!

## 🎮 Theme worlds to choose from

- **🗺️ Adventure World:** The treasure chambers of Pyralia – keep your treasures (data) in magical chests (files)!
- **🐴 Horse Stables:** The stable archive – document everything about horses, riders and tournaments!
- **🚀 Sci-Fi World:** The data pipelines of Space Station Nebula-7 – secure mission data for eternity!

# 🎯 Learning goals
- Read and write files with open()
- Use JSON to store dictionaries
- Use CSV for tabular data
- Avoid errors when accessing files
- Convert data between formats
