## 🧙 Was ist eine Zauberformel?

Eine **Zauberformel** ist wie ein magischer Spruch: eine feste Abfolge von Worten, die eine bestimmte Wirkung erzielt. In der Programmierung sind das die **Befehle** von Python – und die heißen dort **Funktionen**.

Eine Funktion **rufst du auf**, indem du ihren Namen schreibst und Klammern dahinter setzt. Was du dem Zauber mitgibst (die Zutat), steht in den Klammern:

```python
print("Hallo")   # Zauber: print – Zutat: "Hallo"
```

> 🪄 **Merke:** Zauberformel = Funktion. Der **Name** sagt, welcher Zauber, die **Klammern `()`** rufen ihn auf. Ohne Klammern passiert nichts!

Jede Formel, die du meisterst, macht dich zu einem mächtigeren Magier! Später, in Woche 5, lernst du sogar, **eigene** Zauberformeln (Funktionen) zu erfinden.

## ✨ Zauberformel 1: Zauber

`print()` ist dein erster magischer Befehl – eine **Funktion**, die du aufrufst. Er gibt Text auf dem Bildschirm aus.

```python
print("Hallo Welt!")
print("Willkommen in Pyralia!")
```

**Wichtig:** Text muss immer in Anführungszeichen `"` oder `'` stehen! Ein leeres `print()` gibt eine leere Zeile aus – praktisch für mehr Übersicht.
