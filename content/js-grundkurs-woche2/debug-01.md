# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, wirft aber einen Fehler oder gibt etwas
Falsches aus. Bei jeder Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun soll
– ohne zu verraten, was genau kaputt ist.

> 💡 Tipp: Bei Bedingungen schleichen sich besonders gern drei Fehler ein – ein einzelnes `=`
> statt `===`, ein vertauschter oder falsch geschriebener Zweig, oder ein Vergleich zwischen
> unterschiedlichen Datentypen.
