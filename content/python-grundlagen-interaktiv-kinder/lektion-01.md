# Dein erstes Programm 🎉

Ein Programm ist einfach eine Liste von Befehlen, die der Computer der Reihe nach abarbeitet. Mit `print()` gibst du deinen allerersten Befehl: "Zeig das hier auf dem Bildschirm an!" Probier es aus!

```python
print("Hallo!")
```

Text steht immer in Anführungszeichen (`"..."`) – das nennt man einen **String**. Ohne die Anführungszeichen würde Python denken, du meinst eine Variable, und sich beschweren. Zahlen schreibst du dagegen ohne Anführungszeichen:

```python
print(42)
print(3.14)
```

Du kannst `print()` auch mehrmals hintereinander benutzen – jeder Aufruf landet in einer neuen Zeile:

```python
print("Hallo!")
print("Wie geht's?")
```

Mit `#` schreibst du Kommentare – das sind Notizen nur für dich (oder für andere, die deinen Code später lesen). Python überspringt sie einfach beim Ausführen, sie haben also keine Auswirkung auf das Programm.

```python
# Das ist ein Kommentar – Python überspringt ihn
print("Tschüss!")
```

**Kleiner Tipp:** Vergisst du eines der Anführungszeichen bei Text, meldet Python einen Fehler (`SyntaxError`). Das ist völlig normal – auch erfahrene Programmierer:innen vertippen sich ständig. Einfach die Fehlermeldung lesen und nochmal schauen!
