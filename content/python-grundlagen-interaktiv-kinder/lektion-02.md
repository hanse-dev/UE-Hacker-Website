# Variablen – dein Gedächtnis 🧠

Eine Variable ist wie eine Schatztruhe mit einem Namen. Du legst etwas hinein und kannst es jederzeit wieder rausnehmen!

```python
tier = "Hund"
print(tier)  # gibt "Hund" aus
```

Du kannst den Inhalt jederzeit ändern:

```python
tier = "Katze"
print(tier)  # gibt jetzt "Katze" aus
```
