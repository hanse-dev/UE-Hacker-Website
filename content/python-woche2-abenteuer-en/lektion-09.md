# 🔮 Spell Formula input(): Consulting the Oracle

`input()` is a spell formula (function) that asks a question and **returns** the user's answer. The question goes inside the parentheses. The answer is always a **🔥 Fire element (text)** – even if someone types a number! For 🪨 Earth or 💧 Water you have to convert it:

```python
name = input("What is your name? ")             # Fire (str)
age = int(input("How old are you? "))           # Fire -> Earth (str -> int)
```

In the browser, an input box opens for `input()`.
