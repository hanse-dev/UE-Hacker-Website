# Links

```html
<a href="https://www.tagesschau.de">Nachrichten</a>
```

Der Text zwischen `<a>` und `</a>` ist das, worauf man klickt. Schreib ihn so, dass man weiß, wohin der Link führt – „Nachrichten der Tagesschau“ statt „hier klicken“.

## Arten von Adressen

| href | führt zu |
|---|---|
| `https://de.wikipedia.org/wiki/Schach` | einer anderen Website (**absolute** Adresse) |
| `kontakt.html` | einer Seite neben der aktuellen (**relative** Adresse) |
| `mailto:info@example.org` | einer neuen E-Mail an diese Adresse |
| `#termine` | einer Stelle auf derselben Seite (nächste Lektion) |

Mit `target="_blank"` öffnet sich ein Link in einem neuen Tab. Nutze das sparsam – meist wollen Besucher selbst entscheiden.

> 💡 Auch Bilder können Links sein: Steck das `img` einfach in ein `a`.
