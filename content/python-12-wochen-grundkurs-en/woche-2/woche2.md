# Week 2 – Data types and variables

## Topic: The four elements of data

Learn how Python organises different kinds of data. Master the four fundamental data types for writing more complex programs.

## The three worlds

### 🗡️ Adventure World
Dive into the magical world of elements! Learn the four magical element types like a true alchemist and turn lead into gold.

### 🐴 Horses World
Welcome to the stables! Discover the four hoof-beat types of the horse world. Manage feed stores and plan training sessions.

### 🚀 Sci-Fi World
Aboard the space station, learn the four quantum types. Analyse fleet formations and manage energy depots.

## Learning goals

- **Master f-Strings** for modern text formatting
- **The four data types**: String, Integer, Float, Boolean
- **Perform operations**: maths and text manipulation
- **Type conversions** for flexible data processing
