# 🦘 Übung 5: Sprung – Wahrheitswerte

Ein Sprung gelingt oder er reißt – es gibt nur **zwei Zustände**. Genauso kennt ein **Boolean** (`bool`) nur zwei Werte: `True` (wahr) und `False` (falsch).

> ⚠️ Schreibe sie genau so: großes **T** bzw. **F**, **ohne** Anführungszeichen!

```python
hat_sattel = True
ist_besucht = False
print(f"Hat Sattel: {hat_sattel}")
print(type(hat_sattel))   # <class 'bool'>
```

Wahrheitswerte entstehen auch durch **Vergleiche**: `alter > 5` fragt „Ist das Alter größer als 5?" und ergibt `True` oder `False`.
