# Dein erstes Programm

`print()` gibt Text oder Werte auf der Konsole aus. Es ist die grundlegendste Python-Funktion – du wirst sie in jedem Programm wiederfinden, ob zum Debuggen oder als echte Ausgabe.

```python
print("Hallo Welt")
print(42)
print(3.14)
```

Mit `#` schreibst du Kommentare – Python ignoriert sie. Wichtig für Erklärungen im Code.
