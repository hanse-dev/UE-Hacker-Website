# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, gibt aber etwas Falsches aus. Bei jeder
Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun soll – ohne zu verraten, was
genau kaputt ist.

> 💡 Tipp: Bei Objekten schleichen sich besonders gern vier Fehler ein – Punkt-Notation statt
> eckiger Klammer bei einer Variable als Property-Name, ein vergessener Methodenaufruf mit `()`,
> ein Tippfehler im Property-Namen, und eine falsche Property beim Durchgehen eines Arrays aus
> Objekten.
