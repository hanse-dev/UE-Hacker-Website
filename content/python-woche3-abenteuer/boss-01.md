# ⭐⭐⭐⭐☆ Extra-Herausforderung 1: Das Magie-Quiz

> ⚠️ Schwieriger! Die Extra-Herausforderungen kombinieren alles aus dieser Woche – sie sind freiwillig.

Teste dein Wissen über magische Künste! Das Quiz hat 5 Fragen. Jede Antwort ist ein Wahrheitswert (`True` = richtig, `False` = falsch). Pro richtiger Antwort gibt es 100 Punkte, danach folgen Note, Serienbonus und Zertifikat.

Tipp: Punkte zählst du mit `punkte = punkte + 100`. Python rechnet zuerst rechts: alte Punkte plus 100. Das Ergebnis wird dann wieder in `punkte` gespeichert – aus 200 wird so 300.
