# ⭐⭐☆☆☆ Mission 1: The Security Scanner

The security scanner checks who is allowed to enter the bridge!

**Step 1** – Capture the access data in variables (rank, ID card, emergency).
**Step 2** – Write the access rule with `or`: rank >= 5 **or** ID card **or** emergency.
**Step 3** – Add a rejection message with `else`.

**Bonus (optional, not checked):** Only require an ID card when the rank is below 8!
