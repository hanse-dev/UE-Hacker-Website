# Hallo, JavaScript!

Willkommen zu deiner ersten Woche **JavaScript** – der Sprache, in der (fast) jede Webseite und
jedes Browserspiel geschrieben ist. Dein Code läuft hier in einem eigenen, abgeschotteten Bereich
und die Ausgabe landet unten in einer eigenen Box – genau wie die **Konsole**, die echte
Programmierer:innen im Browser benutzen.

Dein wichtigstes Werkzeug in dieser Woche: `console.log(...)`. Es schreibt etwas in die Ausgabe:

```js
console.log('Hallo Welt!');
```

Du kannst auch mehrere Zeilen hintereinander ausgeben lassen:

```js
console.log('Erste Zeile');
console.log('Zweite Zeile');
```

Und du kannst Notizen in deinen Code schreiben, die JavaScript komplett ignoriert – **Kommentare**,
eingeleitet mit `//`:

```js
// Das hier ist nur eine Notiz für Menschen, kein Code
console.log('Das hier läuft wirklich');
```

> 💡 Jeder Klick auf „Ausführen" oder „Prüfen" startet deinen Code frisch neu – so wie du es aus der
> JS-Spielewerkstatt vielleicht schon kennst.

In jeder Lektion dieser Woche bekommst du zuerst ein fertiges Beispiel zum Ausführen und Anschauen
– erst danach bist du mit einer eigenen Aufgabe dran.
