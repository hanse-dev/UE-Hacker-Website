# Mission: Design-Makeover

Die Seite unten hat noch gar kein Design. Gib ihr ein eigenes – du entscheidest, wie es aussieht. Dein CSS soll aber diese Dinge enthalten:

- eine **Variable** `--hauptfarbe` in `:root`, die du an mindestens **zwei** Stellen mit `var(--hauptfarbe)` benutzt
- für den `body` eine eigene **Schrift** und eine **Hintergrundfarbe**
- eine eigene Farbe für die Überschrift `h1`
- einen Hintergrund für alle Elemente mit `class="karte"`
- kleinere Schrift **nur** für den Absatz im `footer`
