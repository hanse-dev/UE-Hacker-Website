# ⚖️ Zauberformel 1: if

Willkommen, weiser Abenteurer! Du erreichst den **Kreuzweg des Schicksals** – ein magischer Ort, an dem jede Entscheidung über Sieg oder Niederlage entscheidet. Hier lernst du, wie dein Programm **Entscheidungen** trifft.

Mit `if` prüft Python eine **Bedingung** und führt den Code darunter **nur aus, wenn sie wahr ist** (`True`). Das Ergebnis einer Bedingung ist ein Boolean – genau wie in Woche 2!

```python
level = 5
if level >= 5:
    print("Du bist bereit für die Quest!")
```

Zwei Dinge sind wichtig:

- Hinter der Bedingung steht ein **Doppelpunkt** `:`
- Der Code, der zum `if` gehört, ist **eingerückt** (4 Leerzeichen). Die Einrückung sagt Python: *"Das hier gehört dazu."*

Ist die Bedingung falsch, wird der eingerückte Block einfach übersprungen – es passiert nichts.

Du kannst auch Wahrheitswerte und Texte prüfen:

```python
hat_schluessel = True
if hat_schluessel:
    print("Die Tür öffnet sich!")
```
