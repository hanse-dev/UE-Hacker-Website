# Listen – viele Werte auf einmal 📋

Eine Liste speichert mehrere Werte hintereinander. Der erste Eintrag hat den Index 0.

```python
tiere = ["Hund", "Katze", "Maus"]
print(tiere[0])   # gibt "Hund" aus
print(tiere[-1])  # gibt "Maus" aus (letztes Element!)
```

Listen können alles enthalten: Texte, Zahlen, ja sogar andere Listen!
