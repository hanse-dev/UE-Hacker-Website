# 📟 Systemprotokoll 4: Kommazahlen

Ein **Float** (`float`) ist eine Zahl **mit Komma** – für präzise Werte wie Geschwindigkeiten oder Koordinaten. Python nutzt einen **Punkt**, kein Komma:

```python
geschwindigkeit = 2.5
koordinate_x = 127.35
print(type(geschwindigkeit))   # <class 'float'>
```

> 💡 `5` ist ein Integer, aber `5.0` ist ein Float – der Punkt macht den Unterschied!
