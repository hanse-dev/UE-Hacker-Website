# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, wirft aber einen Fehler oder gibt etwas
Falsches aus. Bei jeder Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun soll
– ohne zu verraten, was genau kaputt ist. Lies die Fehlermeldung nach einem Klick auf „Prüfen"
genau: sie sagt dir oft schon, wo das Problem liegt.

> 💡 Tipp: Vergleiche den Code Zeichen für Zeichen mit dem, was du in den letzten Lektionen gelernt
> hast – Anführungszeichen, Groß-/Kleinschreibung und Rechenzeichen sind die häufigsten Fehlerquellen.
