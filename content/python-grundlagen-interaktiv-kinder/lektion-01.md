# Dein erstes Programm 🎉

Mit `print()` bringst du Python dazu, etwas auf dem Bildschirm anzuzeigen. Probier es aus!

```python
print("Hallo!")
```

Mit `#` schreibst du Kommentare – das sind Notizen nur für dich. Python ignoriert sie einfach.

```python
# Das ist ein Kommentar – Python liest ihn, macht aber nichts
print("Tschüss!")
```
