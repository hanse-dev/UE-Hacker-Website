# 🎤 Übung 4: Den Benutzer fragen

`input()` ist eine Funktion, die dir etwas **zurückgibt**: die Antwort des Benutzers. Sie hält das Programm an und wartet auf eine Eingabe. Dafür öffnet sich ein kleines **Eingabefenster** im Browser. Die Antwort wird als **Text (String)** gespeichert.

```python
name = input("Wie heißt dein Pferd? ")
print("Willkommen, " + name + "!")
```

> 💡 Tippe im Eingabefenster etwas ein und bestätige mit OK – dein Programm arbeitet dann mit deiner Antwort weiter.
