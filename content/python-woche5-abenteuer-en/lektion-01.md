# 📜 Spell Formula 1: Defining a function

Welcome to the **Library of Repetitions**, young mage! The librarian says: *"You write a good spell down only once – and cast it as often as you like."*

That is exactly what a **function** does: a piece of code with a name that you can call again and again.

```python
def greet_hero():
    print("Welcome, brave hero!")
    print("Your adventure begins now!")

greet_hero()
greet_hero()
```

**Step by step:**
1. **`def`** starts the definition – here you only *define* the spell
2. **`greet_hero`** is the name of the formula
3. **`()`** and the **colon `:`** always belong there
4. The **indented** code (4 spaces) is the spell itself
5. **`greet_hero()`** – with parentheses – *casts* the spell

> ⚠️ Defining does not run anything yet! Only the **call with parentheses** runs the code. Without parentheses (`greet_hero`) you do not speak the spell.

Every call runs the code again – so you save yourself copy & paste.
