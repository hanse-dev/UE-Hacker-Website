# ⭐⭐⭐☆☆ Mission 2: The Treasure Chest

A magical chest only gives up its prize when the right password is spoken! There is a **master password** (full treasure) and a **guest password** (partial treasure). Anything else is wrong.

Check the input with `if` and `elif`; `else` catches everything else.

**Bonus (optional, not checked):** Give different hints for wrong passwords!
