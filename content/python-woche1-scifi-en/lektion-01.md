# 🚀 Launch sequence: System Protocol 1

Welcome, Commander! You enter the state-of-the-art **Space Station Nebula-7** – a centre for technological innovations and interstellar adventures. This week you will learn five **system protocols**:

1. Display text with `print()`
2. Store information in **variables**
3. Combine texts and variables into messages
4. Ask the user with `input()`
5. Comments to explain your code

## 🔬 What is a system protocol?

A **system protocol** is like a command set for the space station – a fixed instruction that the computer understands and executes. In Python these instructions are called **functions**.

You **call** a function by writing its name followed by parentheses. Whatever you hand to it goes inside the parentheses:

```python
print("Hello")   # function: print – what is handed over: "Hello"
```

> 📡 **Remember:** system protocol = function. The **name** says which protocol, the **parentheses `()`** call it. Without parentheses nothing happens! Later, in Week 5, you will even invent your own protocols (functions).

## 📟 System Protocol 1: Command

`print()` is your first command – a **function** you call. It displays text on the screen.

**Important:** Text must always be in quotation marks `"` or `'`! An empty `print()` prints an empty line – handy for a better overview.
