# 🔥 Feuer: Text (`str`)

Das Feuer-Element ist **Text**: Namen, Zaubersprüche, Sätze. Text steht immer in Anführungszeichen.

```python
zauber = "Feuerball"
beschreibung = "Ein mächtiger Feuerzauber"
print(f"Zauber: {zauber}")
```

## `len()` – der Längenmesser

`len()` ist ebenfalls eine Zauberformel (Funktion): Du gibst ihr einen Text, und sie liefert dir die **Anzahl der Zeichen** zurück. Leerzeichen zählen mit!

```python
name = "Aria"
print(len(name))    # 4
```

> 💡 Auch eine Zahl in Anführungszeichen ist Text: `"42"` ist ein Feuer-Element, `42` ein Erd-Element.
