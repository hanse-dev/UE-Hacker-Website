# 🎤 Lesson 4: Ask the User

`input()` is a function that **gives something back** to you: the user's answer. It pauses the program and waits for input. For this, a small **input window** opens in the browser. The answer is stored as **text (String)**.

```python
name = input("What is your horse's name? ")
print("Welcome, " + name + "!")
```

> 💡 Type something into the input window and confirm with OK – your program then carries on working with your answer.
