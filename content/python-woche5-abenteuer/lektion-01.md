# 📜 Zauberformel 1: Eine Funktion definieren

Willkommen in der **Bibliothek der Wiederholungen**, junger Magier! Die Bibliothekarin sagt: *"Einen guten Zauber schreibst du nur einmal auf – und wirkst ihn, so oft du willst."*

Genau das macht eine **Funktion**: ein Stück Code mit einem Namen, das du immer wieder aufrufen kannst.

```python
def gruesse_held():
    print("Willkommen, tapferer Held!")
    print("Dein Abenteuer beginnt jetzt!")

gruesse_held()
gruesse_held()
```

**Schritt für Schritt:**
1. **`def`** startet die Definition – hier legst du den Zauber nur *fest*
2. **`gruesse_held`** ist der Name der Formel
3. **`()`** und der **Doppelpunkt `:`** gehören immer dazu
4. Der **eingerückte** Code (4 Leerzeichen) ist der Zauber selbst
5. **`gruesse_held()`** – mit Klammern – *wirkt* den Zauber

> ⚠️ Beim Definieren passiert noch nichts! Erst der **Aufruf mit Klammern** führt den Code aus. Ohne Klammern (`gruesse_held`) sprichst du den Zauber nicht aus.

Jeder Aufruf führt den Code erneut aus – so sparst du dir Copy & Paste.
