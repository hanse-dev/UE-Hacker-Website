# 🎯 The challenge: Don't reinvent the wheel!

You face a huge task and need to perform complex calculations. Instead of writing every function yourself, Python already has ready-made solutions.

With the right modules you can access powerful libraries and extend your programs many times over!

## 🎮 Theme worlds to choose from

- **🗺️ Adventure World:** Enter the magical library of Pyralia and discover the ancient spell formulas (modules)!
- **🐴 Horse Stables:** Tools and equipment at the stables – everything has its fixed place and purpose!
- **🚀 Sci-Fi World:** Space Station Nebula-7 and its advanced system protocols await you!

# 🎯 Learning goals
- Load and use modules with import
- Use the math module for complex calculations
- Generate random numbers with the random module
- Call functions from modules correctly
- Create and use aliases for modules
- Know the most important functions of math and random
