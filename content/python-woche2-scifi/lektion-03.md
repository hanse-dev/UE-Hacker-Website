# 📟 Systemprotokoll 3: Ganze Zahlen

Ein **Integer** (`int`) ist eine ganze Zahl ohne Komma – perfekt für alles, was man zählen kann: Crew-Mitglieder, Decks, Planeten.

```python
crew_anzahl = 250
deck_anzahl = 15
print(type(crew_anzahl))   # <class 'int'>
```

Integer können auch negativ sein (`-5`) und werden **ohne** Anführungszeichen geschrieben – sonst werden sie zu Text!
