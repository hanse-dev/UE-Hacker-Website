# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, gibt aber etwas Falsches aus. Bei jeder
Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun soll – ohne zu verraten, was
genau kaputt ist.

> 💡 Tipp: Bei Arrays schleichen sich besonders gern Indexfehler ein – ein falscher fester Index,
> ein `.length` ohne `- 1`, eine Schleifengrenze, die eins zu weit geht, oder eine Verwechslung
> zwischen dem Array selbst und dem, was `.push()` zurückgibt.
