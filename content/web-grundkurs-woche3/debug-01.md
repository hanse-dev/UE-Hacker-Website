# Fehlersuche: Bilder, Links, Tabellen

Typische Fehler in dieser Woche:

- **Ein Sprung-Link lädt eine falsche Seite**, statt zu springen: Vor der id fehlt die Raute (`href="galerie"` statt `href="#galerie"`).
- **Ein Bild hat keinen Alternativtext** – sehen kann man das nicht, aber Vorleseprogramme lesen dann nur den Dateinamen vor.
- **In der Tabelle ist plötzlich eine Datenzeile fett:** Dort stehen `th` statt `td`.
