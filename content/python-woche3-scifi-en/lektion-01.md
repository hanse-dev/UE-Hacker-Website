## 📟 System Protocol 1: if

`if` checks a condition and runs code only when the condition is true.

```python
security_level = 5
if security_level >= 5:
    print("Access to main system granted!")
```

> ⚠️ **Important:** The code after `if` must be **indented** (four spaces) – and the `if` line ends with a colon `:`.
