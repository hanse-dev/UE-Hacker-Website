# Entscheidungen mit if 🤔

Mit `if` kann Python entscheiden, was es tun soll. Wenn die Bedingung wahr ist, wird der eingerückte Code ausgeführt.

```python
punkte = 80
if punkte >= 50:
    print("Bestanden!")
```

Mit `else` gibst du an, was passieren soll, wenn die Bedingung **nicht** wahr ist:

```python
punkte = 30
if punkte >= 50:
    print("Bestanden!")
else:
    print("Leider nicht bestanden.")
```

**Wichtig:** Der Code nach `if` und `else` muss eingerückt sein (4 Leerzeichen oder Tab)!
