# f-Strings – Text und Variablen mischen ✨

Mit f-Strings kannst du Variablen direkt in einen Text einbauen. Schreibe einfach `f` vor die Anführungszeichen und `{variable}` für den Wert.

```python
tier = "Katze"
print(f"Mein Lieblingstier ist eine {tier}!")
# gibt aus: Mein Lieblingstier ist eine Katze!
```
