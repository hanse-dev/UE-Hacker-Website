# ⚗️ Elemente verschmelzen

Wie du Elemente kombinierst, hängt von ihrem Typ ab.

## 🪨 Erde und 💧 Wasser: rechnen

```python
gold_a = 150
gold_b = 75
print(gold_a + gold_b)    # 225
print(gold_a - gold_b)    # 75
print(gold_a * 2)         # 300
print(gold_a / 3)         # 50.0  (Teilen ergibt immer eine Kommazahl!)
```

## 🔥 Feuer: zusammenkleben und wiederholen

```python
vorname = "Luna"
nachname = "Silbermond"
print(vorname + " " + nachname)    # Luna Silbermond
print(vorname * 3)                 # LunaLunaLuna
```

## Nicht alles passt zusammen

🔥 Feuer (Text) und 🪨 Erde (Zahl) widersetzen sich einer direkten Verschmelzung mit `+`: `"Level: " + 5` ist ein Fehler. Dafür brauchst du eine Umwandlung – die kommt in der nächsten Lektion.
