# Dictionaries – The Animal Encyclopedia 📖

A dictionary stores key-value pairs – like a real encyclopedia or a card index!

```python
animal_sounds = {"Dog": "barks", "Cat": "meows"}
print(animal_sounds["Dog"])  # prints "barks"
```

You can add new entries:

```python
animal_sounds["Bird"] = "chirps"
print(animal_sounds["Bird"])
```
