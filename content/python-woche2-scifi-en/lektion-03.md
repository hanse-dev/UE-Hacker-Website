# 📟 System Protocol 3: Integers

An **Integer** (`int`) is a whole number without a decimal point – perfect for things you can count: crew members, decks, planets.

```python
crew_count = 250
deck_count = 15
print(type(crew_count))   # <class 'int'>
```

Integers can be negative, too (`-5`), and are written **without** quotation marks – otherwise they become text!
