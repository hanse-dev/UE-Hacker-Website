# 🐎 Lesson 3: Trot – Whole Numbers

The trot has a clear, countable two-beat rhythm. Just as countable are **integers** (`int`): **whole numbers without a decimal point and without quotation marks**, for example the age (`7`) or the height in cm (`168`).

```python
age = 7
height = 168  # cm
print(f"Age: {age} years, height: {height} cm")
print(type(age))   # <class 'int'>
```
