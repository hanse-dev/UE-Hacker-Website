# Lists

Lists are ordered, mutable collections. Index starts at 0.

```python
todos = ["Write code", "Test", "Deploy"]
todos.append("Document")
print(len(todos))   # 4
print(todos[0])     # "Write code"
print(todos[-1])    # "Document"
```

Useful methods: `.append()`, `.remove()`, `.sort()`, `len()`
