# Funktionen – dein eigener Zauberspruch 🪄

Eine Funktion ist ein wiederverwendbarer Code-Block. Du definierst ihn einmal mit `def` und kannst ihn immer wieder aufrufen!

```python
def zaubern():
    print("Abrakadabra!")

zaubern()  # ruft die Funktion auf
zaubern()  # und nochmal!
```

Funktionen können auch Werte entgegennehmen:

```python
def begruessen(name):
    print(f"Hallo, {name}!")

begruessen("Luna")  # gibt "Hallo, Luna!" aus
```
