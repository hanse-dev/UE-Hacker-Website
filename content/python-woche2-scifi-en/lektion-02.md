# 📟 System Protocol 2: Strings and type()

Every piece of information on Nebula-7 has a **quantum type** – like the four states of matter. Python knows four basic types:

| Type | Python name | Example |
|---|---|---|
| Text | `str` (String) | `"Starlight"` |
| Whole number | `int` (Integer) | `250` |
| Decimal number | `float` (Float) | `2.5` |
| Truth value | `bool` (Boolean) | `True` |

The function `type()` shows you the quantum type of any information:

```python
ship_name = "Starlight"
print(type(ship_name))   # <class 'str'>
```

## 🔤 Strings – text data

A **String** is any text in quotation marks – even if it looks like a number: `"250"` is text, not a number!
