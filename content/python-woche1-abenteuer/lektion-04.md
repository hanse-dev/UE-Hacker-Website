# 🎤 Zauberformel 4: Den Nutzer befragen

`input()` ist eine Zauberformel (Funktion), die dir etwas **zurückgibt**: die Antwort des Nutzers. Sie hält das Programm an und wartet auf eine Eingabe. Dafür öffnet sich ein kleines **Eingabefenster** im Browser. Die Antwort wird als **Text (String)** gespeichert.

```python
name = input("Wie heißt dein Held? ")
print("Willkommen, " + name + "!")
```

> 💡 Tippe im Eingabefenster etwas ein und bestätige mit OK – dein Programm arbeitet dann mit deiner Antwort weiter.
