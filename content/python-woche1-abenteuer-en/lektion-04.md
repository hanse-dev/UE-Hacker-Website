# 🎤 Spell Formula 4: Ask the User

`input()` is a spell formula (function) that gives something **back** to you: the user's answer. It pauses the program and waits for input. A small **input window** opens in the browser for this. The answer is stored as **text (String)**.

```python
name = input("What is your hero's name? ")
print("Welcome to Pyralia, " + name + "!")
```

> 💡 Type something into the input window and confirm with OK – your program then carries on with your answer.
