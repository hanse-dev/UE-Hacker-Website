# Feinschliff

Bevor eine Website online geht, prüfen Profis eine **Checkliste**:

- **Titel und Beschreibung:** `title` im `head` – und eine Beschreibung für Suchmaschinen:
  ```html
  <meta name="description" content="Alles übers Skaten: Tricks, Parks und Ausrüstung.">
  ```
- **Sprache:** `lang="de"` am `html`-Element
- **Handy:** viewport-meta-Tag und `max-width: 100%` für Bilder
- **Barrierefreiheit:** Jedes Bild hat einen sinnvollen `alt`-Text, jedes Formularfeld ein `label`, Text hat genug **Kontrast** zum Hintergrund (hellgrau auf weiß ist schwer lesbar).
- **Überschriften:** genau eine `h1`, darunter `h2`, `h3` – ohne Ebenen zu überspringen.

> 💡 Die heruntergeladene Datei kannst du später mit Diensten wie GitHub Pages oder Netlify wirklich ins Internet stellen. Frag dafür eine erwachsene Person um Hilfe.
