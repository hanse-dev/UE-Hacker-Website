# Kleine Übung: Alles zusammen! 🏆

Du hast so viel gelernt! Jetzt kombinieren wir alles:

```python
tiere = ["Hund", "Katze", "Vogel"]
for tier in tiere:
    print(f"Das Tier heißt: {tier}")
```

Und mit einer Funktion:

```python
def verdoppeln(zahlen):
    for z in zahlen:
        print(z * 2)

verdoppeln([1, 2, 3])  # gibt 2, 4, 6 aus
```

Du bist bereit für den großen Kurs! 🚀
