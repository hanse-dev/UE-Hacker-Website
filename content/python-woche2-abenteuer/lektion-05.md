# 💧 Wasser: Kommazahlen (`float`)

Das Wasser-Element ist eine **Kommazahl**. Wichtig: Python nutzt einen **Punkt** statt eines Kommas!

```python
schaden = 23.5
prozent = 87.25
print(f"Schaden: {schaden}, Trefferchance: {prozent}%")
print(type(schaden))     # <class 'float'>
```

Rechnest du mit einem `float`, ist das Ergebnis wieder ein `float` – auch wenn es glatt aufgeht:

```python
print(2.5 * 4)    # 10.0
```
