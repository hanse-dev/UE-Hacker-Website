# Schleifen mit for 🔄

Mit `for` kannst du Code mehrmals ausführen. `range(3)` liefert die Zahlen 0, 1, 2.

```python
for i in range(3):
    print("Hallo!")
# gibt dreimal "Hallo!" aus
```

Du kannst auch über eine Liste von Tieren gehen:

```python
tiere = ["Hund", "Katze", "Vogel"]
for tier in tiere:
    print(tier)
```
