# 📟 System Protocol 2: if-else

`if-else` offers **two paths** – one for a true and one for a false condition. `else` needs no condition of its own and runs for everything else.

```python
signals = 9
if signals >= 15:
    print("Life forms detected!")
else:
    print("Sector empty.")
```

Exactly **one** of the two paths is executed – never both.
