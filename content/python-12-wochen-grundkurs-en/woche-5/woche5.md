# 🎯 The challenge: Reusing code

Writing the same code over and over? It doesn't have to be that way! With functions you can write code blocks once and reuse them as often as you like. Like a wizard who learns a spell and can use it again and again.

Functions are the building blocks of professional programming and make your code clean, efficient, and easy to understand.

## 🎮 Theme worlds to choose from

Choose your preferred learning environment:
- **🗺️ Adventure World:** Create powerful magic formulas and repeat them as often as you like!
- **🐴 Horse Stables:** Develop training routines and apply them to all horses!
- **🚀 Sci-Fi World:** Program ship systems and call them up when needed!

All worlds teach the same Python knowledge – just with different flavour!

# 🎯 Learning goals
- Define functions with `def` and parameters
- Use return values and function calls
- Write docstrings for documentation
- Follow naming conventions for functions
- Create functions with and without return values
- Pass parameters and use default values
