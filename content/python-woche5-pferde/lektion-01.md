# 🐴 Übung 1: Eine Routine definieren

Willkommen in der **Trainingshalle der Perfektion**! Die Trainerin sagt: *"Eine gute Übung entwickelst du einmal – und wiederholst sie mit jedem Pferd."*

Genau das macht eine **Funktion**: ein Stück Code mit einem Namen, das du immer wieder aufrufen kannst.

```python
def begruesse_pferd():
    print("Hallo, Sturmwind!")
    print("Zeit fürs Training!")

begruesse_pferd()
begruesse_pferd()
```

**Schritt für Schritt:**
1. **`def`** startet die Definition – hier legst du die Routine nur *fest*
2. **`begruesse_pferd`** ist der Name der Routine
3. **`()`** und der **Doppelpunkt `:`** gehören immer dazu
4. Der **eingerückte** Code (4 Leerzeichen) ist die Routine selbst
5. **`begruesse_pferd()`** – mit Klammern – *führt* sie aus

> ⚠️ Beim Definieren passiert noch nichts! Erst der **Aufruf mit Klammern** führt den Code aus. Ohne Klammern (`begruesse_pferd`) startet nichts.

Jeder Aufruf führt den Code erneut aus – so sparst du dir Copy & Paste.
