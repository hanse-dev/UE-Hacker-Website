# Datentypen – was steckt dahinter? 🔍

Python kennt verschiedene Arten von Werten:
- **int** – ganze Zahlen wie `42`
- **float** – Kommazahlen wie `3.14`
- **str** – Text wie `"Hallo"`
- **bool** – Wahr oder Falsch: `True` oder `False`

Mit `type()` kannst du herausfinden, welcher Typ ein Wert hat:

```python
print(type(42))       # <class 'int'>
print(type("Hallo"))  # <class 'str'>
```
