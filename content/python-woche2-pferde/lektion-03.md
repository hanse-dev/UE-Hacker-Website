# 🐎 Übung 3: Trab – Ganze Zahlen

Der Trab hat einen klaren, zählbaren Zwei-Takt-Rhythmus. Genauso zählbar sind **Integer** (`int`): **ganze Zahlen ohne Komma und ohne Anführungszeichen**, zum Beispiel das Alter (`7`) oder das Stockmaß in cm (`168`).

```python
alter = 7
stockmass = 168  # cm
print(f"Alter: {alter} Jahre, Stockmaß: {stockmass} cm")
print(type(alter))   # <class 'int'>
```

Mit ganzen Zahlen kannst du rechnen: `+` (plus), `-` (minus), `*` (mal) und `/` (geteilt).

```python
print(168 - 138)   # 30
print(4 * 2)       # 8
```
