# 🎤 System Protocol 4: User Input

`input()` is a function that **returns** something to you: the user's answer. It pauses the program and waits for input. A small **input window** opens in the browser for this. The answer is stored as **text (String)**.

```python
name = input("What is your name, Commander? ")
print("Welcome aboard, " + name + "!")
```

> 💡 Type something into the input window and confirm with OK – your program then carries on with your answer.
