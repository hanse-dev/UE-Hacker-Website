# 📟 System Protocol 6: Operations

**With numbers** you can calculate:

| Operator | Meaning | Example |
|---|---|---|
| `+` `-` | add, subtract | `8 + 4` → `12` |
| `*` | multiply | `8 * 2` → `16` |
| `/` | divide (result is a Float!) | `8 / 2` → `4.0` |

```python
planets = 8
print(planets * 2)    # 16
print(planets / 2)    # 4.0
```

> 💡 Dividing with `/` always gives a decimal number – even when the result comes out even.
