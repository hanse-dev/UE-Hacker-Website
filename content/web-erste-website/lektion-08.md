# Deine fertige Website

Du kennst jetzt alles, was eine richtige Website braucht: Überschriften, Absätze, Listen, Bilder, Links, Farben, Kisten, Klassen und Flexbox. Zeit, alles zusammenzubauen!

## Ein letzter Trick: hover

Mit `:hover` hinter dem Selektor gilt eine Regel nur, **solange die Maus darüber ist**:

```css
.karte:hover {
  background-color: lightyellow;
}
```

So fühlt sich deine Seite lebendig an.

## Deine Seite mitnehmen

Unter jeder Aufgabe gibt es den Knopf **Seite herunterladen**. Er speichert deine Seite als Datei `meine-website.html`. Die kannst du mit einem Doppelklick in jedem Browser öffnen, jemandem per E-Mail schicken oder auf einem USB-Stick mitnehmen.

> 💡 Die Bilder aus `/web-bilder/` lädt die heruntergeladene Seite aus dem Internet – damit sie erscheinen, braucht dein Computer eine Internetverbindung.

## Ausblick: Seiten, die reagieren

HTML und CSS bestimmen, was auf der Seite steht und wie es aussieht. Damit eine Seite auf Klicks **reagiert**, braucht es eine dritte Sprache: **JavaScript**. Im letzten Beispiel bekommst du einen kleinen Vorgeschmack – und im [JavaScript-Grundkurs](/kurs/js-grundkurs) lernst du sie richtig.

Wenn du alle Aufgaben geschafft hast, wartet der **Abschluss-Check** auf dich. Bestehst du ihn, bekommst du dein Zertifikat!
