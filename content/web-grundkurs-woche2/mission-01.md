# Mission: Fanseite

Baue eine **Fanseite** – für eine Band, einen Verein, eine Serie oder ein Spiel. Sie soll so gegliedert sein, wie echte Websites gegliedert sind:

- ein `header` mit der Hauptüberschrift `h1` und einem `nav` mit mindestens drei Links in einer Liste (`ul` → `li` → `a`)
- ein `main` mit mindestens **zwei** `section`-Abschnitten, jeder mit einer `h2`
- in einem Abschnitt eine **nummerierte** Liste (z. B. eine Rangliste oder Lieblingssongs)
- mindestens ein `article` mit `h3`
- ein `footer` mit einer Zeile Text
