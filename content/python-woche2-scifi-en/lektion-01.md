## 📟 System Protocol 1: String Command

The **f-string** is the modern method to fuse text and variables into precise commands. Put an `f` in front of the quotation marks and write variables (or even calculations) in curly braces `{}`:

```python
pilot = "Zara"
print(f"Hello {pilot}!")          # Hello Zara!
print(f"Total: {75 + 25}%")       # Total: 100%
```

> ⚠️ **Important:** Without the `f` in front, Python prints the curly braces literally – nothing gets filled in!
