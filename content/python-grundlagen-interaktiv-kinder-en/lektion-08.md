# Functions – Your Own Magic Spell 🪄

A function is a reusable block of code. You define it once with `def` and can call it again and again!

```python
def cast_spell():
    print("Abracadabra!")

cast_spell()  # calls the function
cast_spell()  # and again!
```

Functions can also take values:

```python
def greet(name):
    print(f"Hello, {name}!")

greet("Luna")  # prints "Hello, Luna!"
```
