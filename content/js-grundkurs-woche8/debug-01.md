# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, gibt aber etwas Falsches aus (oder wirft
einen Fehler). Bei jeder Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun
soll – ohne zu verraten, was genau kaputt ist.

> 💡 Tipp: Bei Klassen schleichen sich besonders gern vier Fehler ein – ein vergessenes `this.` im
> Konstruktor, ein vergessenes `new` beim Erzeugen einer Instanz, ein vergessenes `this.` in einer
> Methode, und ein vergessener Methodenaufruf mit `()`.
