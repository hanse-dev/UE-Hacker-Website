# 📟 System Protocol 4: Floats

A **Float** (`float`) is a number **with a decimal point** – for precise values like speeds or coordinates. Python uses a **point**, not a comma:

```python
speed = 2.5
coordinate_x = 127.35
print(type(speed))   # <class 'float'>
```

> 💡 `5` is an Integer, but `5.0` is a Float – the decimal point makes the difference!
