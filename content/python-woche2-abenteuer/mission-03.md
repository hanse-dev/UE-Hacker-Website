# ⭐⭐⭐⭐☆ Mission 3: Das Orakel der vier Elemente

Die letzte Prüfung: Befrage das Orakel nach den Elementen eines Suchenden. Achte darauf, jede Antwort in den passenden Typ umzuwandeln. Tippe im Eingabefenster genau die Werte ein, die in der Aufgabe stehen.

**Bonus (freiwillig, ohne Prüfung):** Gib mit `type()` das Element jeder Antwort aus.
