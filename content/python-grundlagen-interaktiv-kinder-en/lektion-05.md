# Decisions with if 🤔

With `if` Python can decide what to do. If the condition is true, the indented code runs.

```python
points = 80
if points >= 50:
    print("Passed!")
```

With `else` you say what should happen when the condition is **not** true:

```python
points = 30
if points >= 50:
    print("Passed!")
else:
    print("Not quite there yet.")
```

**Important:** The code after `if` and `else` must be indented (4 spaces or Tab)!
