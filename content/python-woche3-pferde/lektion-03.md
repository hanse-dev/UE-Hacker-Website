# 🔀 Übung 3: if-else

`if-else` bietet **zwei Wege**: einen, wenn die Bedingung wahr ist, und einen für alles andere.

```python
hoehe = 120
if hoehe <= 100:
    print("Leichte Hürde gemeistert!")
else:
    print("Anspruchsvolle Hürde!")
```

> 🐴 **Wichtig:** `else` hat **keine Bedingung** – es greift, wenn die `if`-Bedingung **nicht** zutrifft. Auch hinter `else` steht ein Doppelpunkt, und der Code darunter wird eingerückt.

Genau **einer** der beiden Wege wird ausgeführt – nie beide, nie keiner.
