## 📟 System Log 1: The for Loop – The Time Loop

A **for loop** repeats code for every element in a sequence:

```python
for i in range(5):
    print(f"Time Cycle {i+1}: Systems synchronized")
```

1. **`for`** starts the time loop
2. **`i`** is a placeholder that holds the current number on each pass
3. **`range(5)`** delivers the numbers 0, 1, 2, 3, 4
4. **`:`** ends the loop definition
5. The **indented code** runs on every pass

> 💡 `range(5)` starts at 0 and stops *before* 5 – so `i` is 0, 1, 2, 3, 4. That is why we print `i+1` to count from 1 to 5.
