# Fehlersuche

Hier ist etwas kaputter Code – kannst du die Fehler finden und beheben?

Jeder Code-Block unten sollte eigentlich funktionieren, gibt aber etwas Falsches aus (oder wirft
einen Fehler). Bei jeder Aufgabe steht ein **Ziel:**, das beschreibt, was der Code am Ende tun
soll – ohne zu verraten, was genau kaputt ist. Zum Prüfen wird der Knopf automatisch angeklickt.

> 💡 Tipp: Bei DOM-Code schleichen sich besonders gern vier Fehler ein – ein fehlendes `#` vor
> einer ID, ein falsch geschriebener Event-Name, das falsche Element im Klick-Handler und eine
> falsche Reihenfolge zwischen Verändern und Auslesen.
