# Loops with for 🔄

With `for` you can run code multiple times. `range(3)` gives the numbers 0, 1, 2.

```python
for i in range(3):
    print("Hello!")
# prints "Hello!" three times
```

You can also loop over a list of animals:

```python
animals = ["Dog", "Cat", "Bird"]
for animal in animals:
    print(animal)
```
