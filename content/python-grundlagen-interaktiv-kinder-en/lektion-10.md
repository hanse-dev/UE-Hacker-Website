# Mini Challenge: Putting It All Together! 🏆

You have learned so much! Now let's combine everything:

```python
animals = ["Dog", "Cat", "Bird"]
for animal in animals:
    print(f"The animal is called: {animal}")
```

And with a function:

```python
def double(numbers):
    for n in numbers:
        print(n * 2)

double([1, 2, 3])  # prints 2, 4, 6
```
