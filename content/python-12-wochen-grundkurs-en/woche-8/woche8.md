# 🎯 The challenge: Organising data in a structured way!

You have lots of data and need to sort it. Instead of unstructured lists, you need a way to organise data with names and store immutable values.

With dictionaries and tuples you can structure your data perfectly!

## 🎮 Theme worlds to choose from

- **🗺️ Adventure World:** The treasure chambers of Pyralia – organise your treasures (dictionaries) and magical seals (tuples)!
- **🐴 Horse Stables:** Order at the stables – every horse has its folder, every position is fixed!
- **🚀 Sci-Fi World:** The data archives of Space Station Nebula-7 – structured data storage!

# 🎯 Learning goals
- Create dictionaries with {}
- Access values via keys
- Create and use tuples with ()
- Understand immutability
- Build nested structures
