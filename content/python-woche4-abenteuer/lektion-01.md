# 🔄 Zauberformel 1: Die for-Schleife

Willkommen, tapferer Abenteurer! Du stehst vor dem **Turm der Wiederholungen** – einem magischen Ort, an dem sich Muster wiederholen und Zyklen die Realität formen. Die **Turmwächterin** sagt: *"Wer nur einmal zaubern kann, kommt nicht weit. Wer einen Zauber wiederholen kann, öffnet jede Tür."*

Eine `for`-Schleife führt Code **mehrmals hintereinander** aus. Mit `range(n)` sagst du Python, wie oft:

```python
for i in range(5):
    print(f"Durchlauf {i}")
```

**Schritt für Schritt:**
1. `range(5)` erzeugt die Zahlen 0, 1, 2, 3, 4
2. Python speichert die aktuelle Zahl in `i`
3. Der **eingerückte** Code wird ausgeführt
4. Das wiederholt sich, bis alle Zahlen durch sind

> ⚠️ Vergiss nicht den **Doppelpunkt** hinter `range(5)` und die **Einrückung** (4 Leerzeichen) darunter!

`range(5)` zählt also **0 bis 4** – die 5 selbst ist nicht dabei.
