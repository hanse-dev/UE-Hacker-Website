# 🔄 Spell Formula 1: The for Loop

Welcome, brave adventurer! You stand before the **Tower of Repetitions** – a magical place where patterns repeat and cycles shape reality. The **Tower Guardian** says: *"Whoever can cast a spell only once will not get far. Whoever can repeat a spell opens every door."*

A `for` loop runs code **several times in a row**. With `range(n)` you tell Python how often:

```python
for i in range(5):
    print(f"Run {i}")
```

**Step by step:**
1. `range(5)` creates the numbers 0, 1, 2, 3, 4
2. Python stores the current number in `i`
3. The **indented** code is executed
4. This repeats until all the numbers are used up

> ⚠️ Don't forget the **colon** after `range(5)` and the **indentation** (4 spaces) below it!

So `range(5)` counts **0 to 4** – the 5 itself is not included.
